# Receh Frontend

Frontend Receh dibuat menggunakan React 19 dan Vite.

## Menjalankan

```bash
npm install
npm run dev
```

Atur URL backend melalui file `.env`:

```env
VITE_API_URL=http://localhost:3000
```

## Fitur

- Dashboard ringkasan keuangan per bulan.
- Pengaturan uang bulanan dengan pos Pokok, Nabung, dan Belanja.
- Perhitungan penggunaan dana secara berjenjang.
- Tambah, edit, dan hapus transaksi.
- Pencarian dan filter transaksi berdasarkan kategori serta pos anggaran.
